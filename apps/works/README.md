# Works

업체가 기술자에게 일감을 의뢰하고 공정표를 관리할 수 있는 서비스입니다.

## 시작하기

### 요구사항

- Node.js 24+
- pnpm 10+

### 설치

```bash
# 의존성 설치
pnpm install
```

### 환경변수 설정

```bash
cp .env.example .env
```

환경변수 파일(.env)을 생성한 후, 필요에 따라 값을 수정하세요.

### 스크립트

```bash
pnpm dev          # 개발 서버 시작
pnpm build        # 프로덕션 빌드
```
