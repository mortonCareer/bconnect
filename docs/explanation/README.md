# Explanation

> **For**: "왜 이렇게 결정했나"가 궁금한 사람.
> **You'll be able to**: 시스템 디자인 결정의 컨텍스트, 트레이드오프, 대안을 이해한다.

Explanation은 [Diátaxis](https://diataxis.fr/explanation.html) 4분할 중 이해 카테고리. WHAT/HOW가 아닌 **WHY**에 집중한다. ADR은 이 카테고리의 핵심 형식.

작성 룰: [`how-to/write-docs.md`](../how-to/write-docs.md)
