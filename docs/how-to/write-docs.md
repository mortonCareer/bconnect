# 문서 작성법

> 대상: 모든 개발자<br>
> 학습 목표: 문서를 목적에 알맞게 작성하고, 관리할 수 있다

[Diátaxis](https://diataxis.fr) 프레임워크에 따라 `/docs` 디렉터리에 문서를 생성한다.

## 링크 형식

- 내부 문서 : `[문서 제목](상대경로)`
- 외부 문서 : `[제공자 : 문서 제목](URL)`
- 내부 파일 : `[파일명](상대경로)`
- 내부 이슈 : `[#NNN](URL)`
- 내부 PR : `[PR #NNN](URl)`
- 외부 이슈 : `[org/repo#NNN](URL)`
- ADR : `[ADR-NNNN](상대경로)`
